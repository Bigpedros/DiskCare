Come decidere

  1. Se non lo usi da molto tempo, controlla.Il fatto che sia vecchio non significa automaticamente che sia inutile.
  2. Se è un setup già usato, valuta.Spesso può essere riscaricato, ma la scelta resta tua.
  3. Se è un backup, verifica prima.Potrebbe contenere file importanti.
  4. Se hai dubbi, usa la quarantena.È la strada più prudente e reversibile.

Aree di sistema

DiskCare le analizza e le mostra, ma le segnala come delicate. Nella PWA non vengono escluse dalla scansione solo perché appartengono a C:, D: o a un percorso di sistema.

Attenzione: questa è una segnalazione, non un blocco. Il browser decide quali cartelle puoi autorizzare.
